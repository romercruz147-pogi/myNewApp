# newMyapp (React Native CLI)

Reconstruction scaffold matching the provided Romers Vendo behavior blueprint:
- Firebase auth + Firestore user/device model
- React Navigation stack route graph
- ESP32 control/status APIs
- IoT backend device login
- Vendo control 3s polling behavior
- WiFi setup flow and settings/logout

## Next steps
1. `cd newMyapp && npm install`
2. Add `.env` values for Firebase keys and backend URL.
3. Configure native Android Google Sign-In settings.
4. Run `npm run android`.
