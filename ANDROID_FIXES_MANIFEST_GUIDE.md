## Part 1: Android Manifest Configuration

### File Location
```
myApp/android/app/src/main/AndroidManifest.xml
```

### Required Permissions for Romers Vendo

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
  
  <!-- REQUIRED: Internet access for backend communication -->
  <uses-permission android:name="android.permission.INTERNET"/>
  
  <!-- RECOMMENDED: Network state for WiFi detection -->
  <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
  
  <!-- OPTIONAL: Change network (for advanced WiFi management) -->
  <uses-permission android:name="android.permission.CHANGE_NETWORK_STATE"/>
  
  <!-- OPTIONAL: Vibration for haptic feedback -->
  <uses-permission android:name="android.permission.VIBRATE"/>
  
  <!-- For file access if needed -->
  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/>
  <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
  
  <application>
    <!-- Your app config -->
  </application>
</manifest>
```

### Check Your Manifest

Current file: `myApp/android/app/src/main/AndroidManifest.xml`

Verify it has:
```xml
<uses-permission android:name="android.permission.INTERNET"/>
```

If missing, add it.

## Part 2: Cleartext HTTP Traffic Configuration

### Problem
Android 9+ blocks unencrypted HTTP by default for security.

### Solution: Create Network Security Config

1. Create file: `myApp/android/app/src/main/res/xml/network_security_config.xml`

2. Add content:
```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
  <!-- Allow cleartext (HTTP) for local development only -->
  <domain-config cleartextTrafficPermitted="true">
    <!-- Local network IPs -->
    <domain subdomains="true">192.168.0.0</domain>
    <domain subdomains="true">10.0.0.0</domain>
    <domain subdomains="true">172.16.0.0</domain>
    <!-- Localhost -->
    <domain subdomains="true">localhost</domain>
  </domain-config>
  
  <!-- Production: Only allow HTTPS -->
  <domain-config cleartextTrafficPermitted="false">
    <domain subdomains="true">api.yourdomain.com</domain>
  </domain-config>
</network-security-config>
```

3. Reference in AndroidManifest.xml:
```xml
<application
  android:networkSecurityConfig="@xml/network_security_config"
  ...>
</application>
```

### For Production
```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
  <!-- All traffic must be HTTPS in production -->
  <domain-config cleartextTrafficPermitted="false">
    <domain subdomains="true">api.example.com</domain>
  </domain-config>
</network-security-config>
```

## Part 3: Google Services Configuration

### File Location
```
myApp/android/app/google-services.json
```

This file is generated by Firebase and links your app to Firebase project.

### Getting google-services.json

1. Go to Firebase Console
2. Project Settings → Android app
3. Click "Download google-services.json"
4. Move to `myApp/android/app/google-services.json`

### Verify Content

Should look like:
```json
{
  "type": "service_account",
  "project_id": "esp-32-iot-39bd2",
  "private_key_id": "...",
  "client_email": "...",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  ...
}
```

### Common Issues

**Issue: "google-services.json not found"**
- File must be in: `myApp/android/app/google-services.json`
- Not in `myApp/android/` or `myApp/`
- Check file path carefully

**Issue: "Incompatible package name"**
- google-services.json must match package name in AndroidManifest.xml
- Default: `com.romersvendo`
- See Part 4 to verify/change package name

## Part 4: Android Package Name

### Check Current Package Name

File: `myApp/android/app/src/main/AndroidManifest.xml`

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.romersvendo">
```

The `package="com.romeindroid.vendo"` value is your package name.

### Change Package Name (If Needed)

**In android/app/src/main/AndroidManifest.xml:**
```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.romersvendo">
```

**In app.json:**
```json
{
  "expo": {
    "android": {
      "package": "com.romersvendo"
    }
  }
}
```

**In android/app/build.gradle:**
```gradle
android {
  defaultConfig {
    applicationId "com.romersvendo"
  }
}
```

### Requirements for Package Name

- Matches Firebase Android app package name
- Matches google-services.json
- Matches SHA fingerprints used
- Standard format: `com.company.appname`

## Part 8: Proguard Configuration

### File: myApp/android/app/proguard-rules.pro

Required for release builds to keep code readable and working:

```proguard
# Firebase
-keep class com.google.firebase.** { *; }
-dontwarn com.google.firebase.**

# Google Sign-In
-keep class com.google.android.gms.** { *; }
-dontwarn com.google.android.gms.**

# React Native
-keep class com.facebook.react.** { *; }
-dontwarn com.facebook.react.**

# Expo
-keep class expo.modules.** { *; }
-dontwarn expo.modules.**

# Keep your app's classes
-keep class com.romersvendo.** { *; }

# Keep Android framework classes
-dontwarn android.**

# Native methods
-keepclasseswithmembernames class * {
    native <methods>;
}

# Enum values
-keepclassmembers enum * {
    public static **[] values();
    public static ** valueOf(java.lang.String);
}

# Keep parcelable classes
-keep class * implements android.os.Parcelable {
    public static final android.os.Parcelable$Creator *;
}
```

## Part 9: Native Module Issues

### Issue: "@react-native-google-signin not found"

**Cause:** Trying to use native module in Expo Go

**Solution:** Build dev build or APK
```bash
cd myApp
eas build --platform android --profile preview
# or
npm run android
```

### Issue: "Gradle build fails"

**Solutions:**
```bash
# 1. Clear gradle cache
cd myApp/android
./gradlew clean

# 2. Delete node_modules and reinstall
rm -rf ../node_modules
npm install

# 3. Rebuild
npm run android
```

### Issue: "Native module version mismatch"

**Cause:** Package.json and gradle dependencies don't match

**Solution:**
```bash
# Update everything
cd myApp
npm install

# Make sure package.json has:
# "@react-native-google-signin/google-signin": "^13.3.1"

cd android
./gradlew build
```

## Part 12: Build and Test

### Debug Build

```bash
cd myApp

npm run android

# Or with explicit debug
cd android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk

adb install -r app/build/outputs/apk/debug/app-debug.apk
```

```bash

# Build release APK
cd android
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk

cd myApp
eas build --platform android --profile production
```

## Part 13: Troubleshooting

### "AndroidManifest.xml not found"
```
File must be at: myApp/android/app/src/main/AndroidManifest.xml
Run: npm run android to auto-generate if missing
```

### "Multiple dex files"
```gradle
# In build.gradle
android {
  defaultConfig {
    multiDexEnabled true
  }
}
```

### "Cleartext traffic not permitted"
```
Create network_security_config.xml (see Part 2)
Reference in AndroidManifest.xml
```

### "Package name mismatch"
```
Verify everywhere:
- AndroidManifest.xml package attribute
- app.json android.package
- build.gradle applicationId
- google-services.json
- Firebase console
All must match: com.romersvendo
```
